موجود ومجهّز حالياً

  • السلة وإرسال طلب مع بيانات الزبون والعنوان والتوصيل.
  • إدارة الطلبات وحالاتها والإحصائيات الأساسية وإعدادات المتجر.
  • ربط API مباشر مع Yalidine أو شركة توصيل أخرى تدعم التكامل، مع متابعة الشحنات.
  • كوبونات وحملات تسويقية وإدارة CRM وربط Meta Pixel وTikTok Pixel.
  • صلاحيات الموظفين ومنشئ صفحات الهبوط والإشعارات وأتمتة الفواتير.

توسعة الموارد والخصائص

عند نمو عدد الزوار والمنتجات والطلبات، نراجع حدود الخدمات ونوسّع الاستضافة أو قاعدة البيانات ونضيف الوظائف المطلوبة.

الدومين الاحترافي، الخطط المدفوعة، خدمات التحليلات الخارجية والتطويرات الجديدة تُحدّد تكلفتها بشكل منفصل قبل التنفيذ. لا يتم احتسابها كخدمات مجانية غير محدودة.

أسئلة قبل القرار

كل شيء واضح قبل ما تبدأ.

إجابات مباشرة على أكثر الأسئلة اللي تهم صاحب المحل.

لا يوجد اشتراك شهري مفروض من منصة متجر في نموذج التطوير الخاص. لكن الدومين والخدمات الخارجية أو الاستهلاك الذي يتجاوز حدود الخطط المجانية قد تكون لها تكاليف مستقلة.

نعم، نموذج المنتجات عام: اسم، تصنيف، سعر، مخزون، صور، وصف وخصائص مرنة. تقدر تستعمله للأدوات، البراغي، الكابلات، الأنابيب، الدهان وغيرها.

ليس في النسخة الحالية. الزبون يرسل طلب شراء، ثم تتصل به لتأكيده ومتابعته. الدفع الإلكتروني وتكاملات الدفع يمكن دراستها كتطوير منفصل حسب مزوّد الخدمة المتاح.

نعم، يمكن إعداد ربط API مع Yalidine أو ناقل آخر يدعم التكامل، مع إنشاء ومتابعة الشحنات ومزامنة الحالات. يلزم حساب تاجر مفعّل وبيانات API. كما يتم ربط Meta Pixel وTikTok Pixel بعد توفير المعرفات وصلاحيات الحسابات.

شهر كامل للمرافقة والدعم والتعديلات المتفق عليها ضمن نطاق المشروع. أي وحدة جديدة كبيرة أو تكامل خارجي يتم تحديده والاتفاق عليه بشكل منفصل.

نعم، البنية مصممة باش تتوسع. يمكن ربط دومين احترافي وتوسعة موارد الاستضافة وإضافة وظائف جديدة عند الحاجة، مع مراجعة التكلفة وحدود الخدمات وقتها.
